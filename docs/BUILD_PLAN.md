# Build plan

## Milestone 1 — foundation
- Verify local install/build on Windows.
- Create Supabase project and apply initial migration.
- Push private GitHub repository and deploy preview to Vercel.

## Milestone 2 — production core
- Supabase Auth: invite-only users, password reset, sessions.
- Profiles, departments, role administration.
- CRUD for clients, projects, tasks, task logs.
- RLS test matrix for owner/admin/manager/staff.

## Milestone 3 — SEO operations
- SEO project workspace, keyword inventory, ranking snapshots, audits, content records.
- Google Search Console and GA4 OAuth integrations.
- WordPress connection with scoped application passwords/API permissions.
- Before/after snapshots, change history, rollback plan.

## Milestone 4 — AI execution
- Server-side AI orchestration and tool registry.
- Job queue for long-running tasks, retries and idempotency.
- Run logs, cost limits, approval gates and evaluation tests.
